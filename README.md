# Regression trees with scikit-learn

> **Archived learning exercise (2022).** Kept as-is; not maintained and not part of the current portfolio.

A worked exercise from the Kaggle "Intro to Machine Learning" course: pick a prediction target (house sale price), build a feature DataFrame, fit a `DecisionTreeRegressor` and inspect its predictions. One notebook, `machine learning model Regression Trees (Sklearn).ipynb`.

Note: https://github.com/nathanmars7/machine-learning-model-regression-trees-sklearn- holds the same notebook from a month earlier. One of the two can be deleted.

## Run it

Open the notebook in Jupyter with `pandas`, `scikit-learn` and the Kaggle `learntools` package installed. The course data is not included in the repo.
